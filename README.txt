অভয়ন কল্যাণ সমিতি — Android APK বিল্ড গাইড
================================================

সবচেয়ে সহজ উপায় (Android Studio ছাড়াই GitHub থেকে APK বানানো):
১. GitHub-এ একটি নতুন Repository তৈরি করুন।
২. এই ZIP-এর সব ফাইল (এবং .github ফোল্ডারসহ) ওই Repository-তে আপলোড (Commit) করুন।
৩. GitHub-এর উপরের "Actions" ট্যাবে গিয়ে "Build Android APK" রান করুন (২ মিনিট লাগবে)।
৪. বিল্ড শেষ হলে নিচে Artifacts থেকে "Ovoyon-Fund-Manager-APK" (app-debug.apk) ডাউনলোড করে ফোনে ইনস্টল করুন!

(বিকল্প: আপনার পিসিতে Android Studio থাকলে এই ফোল্ডারটি ওপেন করে Build > Build APK(s) দিলেই .apk তৈরি হয়ে যাবে।)
